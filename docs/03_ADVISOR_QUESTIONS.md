# 교수님께 여쭤볼 내용

현재 구현에서는 MISO 가격 구간을 늘려 train 300일·test 100일을 구성했습니다. 네 모형은 모두 실행됐지만 논문과 정확한 데이터 조건이 같은지는 확인하기 어렵습니다. 다음 내용을 여쭤보고 싶습니다.

1. 논문의 300일·100일 설명과 3개월·1개월 설명 중 어떤 조건을 기준으로 이해하는 것이 적절한지
2. 현재 선택한 2013-03-27–2014-04-30 구간을 비교 실험의 기준으로 사용해도 되는지
3. 논문에서 사용한 solar zone, MISO price node와 timestamp 결합 방식에 추가로 확인할 수 있는 정보가 있는지
4. 재현 결과와 별도로, 가정을 적어 둔 `operational_corrected` 결과를 연구 과정으로 정리해도 되는지
5. Proposed 모형이 nRMSE는 조금 높지만 realized profit과 gap을 개선한 결과를 목적함수의 trade-off로 해석해도 되는지

상보조건 MILP는 모든 관측에 binary를 두는 대신 목적계수상 필요한 관측에만 남기는 동일한 축소식으로 계산했습니다. 이 재정식화의 설명 수준과 검증 방식이 충분한지도 함께 확인받고 싶습니다.
