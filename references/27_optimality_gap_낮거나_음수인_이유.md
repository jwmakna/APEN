# 27. Optimality gap이 낮거나 음수로 나오는 이유

## 배경

`26_z03_블록9_400일_블록18_120일_4개모형_결과.md`의 실험 결과, gap이 논문
(11.91~15.04%)보다 훨씬 낮게(1~4%대) 나오는 것을 넘어 **z03/블록18의
AR 계열은 gap이 아예 음수(−0.75%, −1.09%)**로 나왔다. 이 문서는 "낮게
나오는 것"과 "음수까지 나오는 것" 두 현상을 하나의 공통 뿌리(벌금율<100%
가 만드는 이익함수의 비대칭 구조)로 통합해 설명한다. 앞부분은
`16_optimality_gap과_오라클_정리.md`의 결론을 z03 데이터로 재확인한
것이고, 뒷부분(§3)은 이번에 새로 규명한 음수 gap의 메커니즘이다.

## 1. 공통 뿌리 — 벌금율(50%)이 100%보다 작다는 것

이익함수(Eq.1a, 3항)에서 약정량 x를 실제발전량 S 기준으로 나눠보면:

```
x ≤ S (부족) 구간:  profit(x) = RP·S + (DP−RP)·x        → DP>RP면 x=S에서 최대
x ≥ S (초과) 구간:  profit(x) = DP·S + (DP−PC)·(x−S),  PC=0.5·DP  → DP>PC 이므로 x가 커질수록 계속 증가!
```

**부족분 벌금(PC)이 DA가격의 50%밖에 안 되므로, 약정을 실제발전량보다
많이 잡아도(x>S) 이익이 계속 늘어난다** — 이 비대칭 구조 하나가 아래
두 현상을 동시에 만든다.

## 2. 현상 ① — gap이 낮게 유지되는 이유 (예측 정확도와 무관)

**핵심 증거**: nRMSE는 모형·블록에 따라 26%~38%로 크게 흔들리는데, gap은
−1%~4% 좁은 범위에 머문다. 즉 gap의 크기를 결정하는 주된 요인은 "얼마나
정확히 예측했는가"가 아니다.

논문 Eq.(13) 오라클(`max(DP,RP)·S_t`, 즉 약정을 {0, S} 중 하나로 고르는
사후 최적)상 **RT≥DA인 시간엔 약정 0이 최적**인데, AR/MLR 같은 회귀
모형은 낮 시간대엔 항상 양의 발전량을 예측하므로 이 선택지를 구조적으로
못 쓴다. 이 "역전 시간대"에서 나오는 손실이 gap의 하한을 만든다.

| 지표 | z03/블록9(400일) | z03/블록18(120일) |
|---|---:|---:|
| RT≥DA인 시간 비율 | 34.4% | 37.2% |
| 그 시간대 평균 (RT−DA) 스프레드 | $7.69 | $7.27 |
| 전체 순 스프레드(DA−RT) 평균 | $0.84 | $1.36 |

예측을 아무리 정확히 해도 "약정을 0으로 하는" 선택지 자체를 예측모델은
쓸 수 없으므로, 이 34~37%의 시간대가 nRMSE와 무관하게 gap의 바닥을
만든다.

## 3. 현상 ② — gap이 음수까지 뒤집히는 이유 (z03/블록18 AR)

§1에서 봤듯 `x>S` 구간에서도 이익은 계속 증가한다. 그런데 논문
Eq.(13)의 오라클은 **{0, S} 두 후보만 비교하고, "약정이 S보다 많은
경우"는 아예 고려하지 않는다** — 이건 우리 구현의 결함이 아니라 **논문
오라클 정의 자체의 사각지대**다(§1의 부등식이 성립하는 한, 어떤
구현이든 이 사각지대는 그대로 존재한다).

z03/블록18에서 AR의 실제 예측을 직접 뜯어본 결과:

```
전체 평균 mismatch(실제−예측)   = −0.062   → AR이 전반적으로 과대예측
DA>RT 시간대 평균 mismatch      = −0.081   → DA>RT일 때 더 심하게 과대예측
DA>RT 시간대(226개) 중 과대예측 비율 = 65.9%
```

DA>RT인 시간대의 65.9%에서 AR이 실제보다 더 많이(x>S) 약정하고
있었다. §1에 따르면 이 구간은 약정이 많을수록 이익이 느는 구간이므로,
**"S만큼만 약정하면 충분히 최적"이라고 평가하는 오라클보다 실제 이익이
더 커져서 gap이 음수로 뒤집힌다.** 오라클의 사각지대(약정>S 미고려)를
AR의 예측 오차(우연한 과대예측 편향)가 파고든 것이다.

z03/블록9에서는 같은 방향의 편향이 있어도 그 크기·시간대 분포가 약해
gap이 양수(+3.7%대)에 머문 것으로 보인다 — 즉 음수 여부는 "과대예측
편향이 DA>RT 시간대와 얼마나 강하게 겹치는가"에 좌우되는 정도의
차이일 뿐, 메커니즘 자체는 두 블록에서 동일하다.

## 4. 종합

| 현상 | 원인 | 예측 정확도와의 관계 |
|---|---|---|
| gap이 전반적으로 낮음 | RT≥DA 시간대(34~37%)에서 "약정 0"을 못 고르는 구조적 손실 | 거의 무관 (nRMSE 10%p 이상 바뀌어도 gap은 1~2%p만 움직임) |
| gap이 아예 음수 | 벌금율<100%로 인해 약정>S도 이익이 느는데, 논문 오라클({0,S})은 이 경우를 안 봄 + 예측이 우연히 DA>RT 시간대에 과대예측 편향 | 예측의 "정확도"가 아니라 "편향의 방향과 시간대 일치 여부"에 좌우됨 |

**두 현상 모두 벌금율이 100%보다 작다는 논문의 파라미터 설정(50%) 자체가
만드는 이익함수의 비대칭 구조에서 나온다** — 모델의 결함이나 재현 오류가
아니라, 이 실험 조건(penalty_rate=50%) 하에서 수학적으로 예정된 결과다.
